# AniLibria для Media Station X

Плагин без сервера: файлы лежат на GitHub Pages, запросы к API идут прямо с iPhone.

## Установка

1. Создай на GitHub публичный репозиторий с именем `ЛОГИН.github.io`.
2. Загрузи в корень `plugin.html`, `app.js` и папку `msx` со `start.json`.
3. Дождись публикации и проверь, что открывается `https://ЛОГИН.github.io/msx/start.json`.
4. В Media Station X открой Settings → Start Parameter → Setup.
5. Введи `логин.github.io` строчными буквами, включи замок (HTTPS), заверши настройку.

## Разделы

Новинки, Популярное, Фильмы, Расписание, Поиск. Качество переключается кнопкой на странице тайтла и запоминается.

## Если появилась ошибка «Нет доступа к API (сеть или CORS)»

1. Разверни `worker.js` как Cloudflare Worker.
2. Впиши его адрес в `PROXY` в начале `app.js`.
3. Загрузи `app.js` заново.
